## Формат теста и правила правки

- Метки уровня: 🟩 знание/понимание, 🟨 применение, 🟥 анализ.
- Между текстом вопроса и вариантами ответа стоит строка `---` (с пустыми строками вокруг); `md2yaml.py` её пропускает.
- Правильный ответ отмечен ✅, после каждого вопроса идёт «Разбор».
- В вопросах с несколькими ответами: +1 балл за каждый верный выбор, −1 за лишний, итог не ниже 0 (в тесте 4 это вопросы 1 и 6).
- Сводка ответов стоит после основных вопросов.
- «Резерв» — вопросы для второй версии теста или пересдачи. Они в том же формате, но в основной тест не входят.

### Как менять тест

- После правки пересчитайте метки уровня и сверьте их с шапкой файла.
- Сверьте строку «Ответы» с ✅ в тексте вопросов.
- Правильный вариант не должен быть самым длинным в списке.

## Структура

```
quizes/
├── src/             общий код и базовые настройки (quiz.py, md2yaml.py, settings.py, settings.yml, тесты)
└── quiz-N-<тема>/   один тест: quiz.ru.md, quiz.yaml, settings.yml, Justfile, README.md, logs/
```

## Пройти тест в терминале

Из корня репозитория (нужен `uv`):

```bash
make quiz-yaml 4                                     # md → yaml с самопроверкой
make quiz-yaml 3                                     # тест и резерв, ревью пропускается
make quiz-yaml 3 SECTION="## Переписанные вопросы"   # только этот раздел
make quiz 4                                          # пройти тест (или make quiz 3); PRESET=exam, QUIZ_LANG=en
make quiz-test                                       # тесты клавиш quiz.py
```

`quiz.py` задаёт вопросы по пресету (см. ниже), после ответа показывает баллы и «Разбор». Клавиши: цифры 1–9 выбирают вариант (в вопросах с несколькими ответами — отмечают и снимают отметку), Enter — ответить, `h` — показать подсказку отдельным пунктом над вопросом или под ним (`quiz.hint_key`, `quiz.hint_position` в `quizes/src/settings.yml` (базовые) или `quizes/quiz-N-*/settings.yml` (переопределения)), `p` — пауза: таймер вопроса стоит, продолжить — любой клавишей (`quiz.pause_key`).

Режим задаёт пресет (ключ `mode`): `immediate` — после каждого ответа верно/неверно, «Разбор» и (если вопрос решён не полностью) готовый промпт; `exam` — до конца теста ничего не показывается, потом таблица результатов по вопросам, «Разбор» и промпты по ошибкам. Промпт можно скопировать в ChatGPT или Claude, чтобы разобрать вопрос там: в нём тема, вопрос, варианты, что выбрал студент, правильный ответ, подсказки и разбор, а в конце просьба объяснить и задать два похожих вопроса. Шаблон — `lang.<код>.prompt_failed` в `quizes/src/settings.yml`, его можно переопределить в `settings.yml` теста. Все промпты прогона сохраняются в `logs/<прогон>-prompts.md`.

### Пресеты

Пресет — готовый сценарий прохождения: режим, язык, какие вопросы брать и в каком порядке. Базовые лежат в [`src/presets.yaml`](src/presets.yaml) (`practice` — тренировка, `exam` — экзамен, `drill` — отработка), свои — в `quizes/quiz-N-*/presets.yaml`: одноимённый пресет переопределяется по ключам, новые добавляются. В итоговом пресете обязательны все ключи, ошибка называет пресет и ключ.

| Ключ | Значения |
|---|---|
| `mode` | `immediate` / `exam` |
| `lang` | `ask` (спросить при старте), `ru`, `en` |
| `sections`, `pick`, `count` | какие вопросы (`main`, `reserve`); `pick`: `first` / `random`; `count`: `all` или число |
| `difficulty_min`, `difficulty_max` | диапазон сложности (простой < средний < сложный) |
| `order`, `topics`, `topic_order` | порядок (`as_is`, `asc`, `desc`, `random`); темы (`all` или список); `mixed` / `grouped` (темы подряд) |
| `shuffle_options`, `hints`, `seed` | перемешать варианты; подсказки вкл/выкл (для экзамена выкл); число делает выбор повторяемым, `null` — случайный (значение пишется в лог) |

Выбор: `make quiz 4 PRESET=exam` (без `PRESET` — меню), список: `make quiz-presets 4`. Пресет, язык, `seed`, id вопросов и порядок вариантов пишутся в лог (`run_start`, `question_shown.option_order`, `answer.picked_orig`).

Каждый запуск пишет лог в `logs/` своего теста (он хранится в git): `quizes/quiz-N-*/logs/<yymmdd-HHMMSS>-<тест>-<пользователь>.jsonl`, одно событие на строку с временем (`t`, `ms` от старта) и id вопроса. События: `run_start` (кто — пользователь, хост, git user.name/email; где — файл теста, каталог, коммит, Python, ОС), `question_shown`, `move` (курсор), `choose` / `unchoose` (вариант и клавиша), `hint_shown`, `pause` / `resume`, `answer` (выбор, верные, баллы, время без пауз, подсказка, число переключений), `run_end` или `interrupted`. Кто проходит, задаёт `log.identity` в `quizes/src/settings.yml` (базовые) или `quizes/quiz-N-*/settings.yml` (переопределения): `os_git` (по умолчанию — пользователь ОС), `ask` (спросить имя при старте) или `env` (переменная из `log.identity_env`, без неё — ошибка).

Подсказка — строка `Подсказка: ...` после вариантов ответа; их может быть несколько, порядок в тексте = порядок показа (от лёгкой к подробной): клавиша подсказки открывает следующую. Для каких уровней сложности подсказка обязательна, задаёт `quizes/src/settings.yml` (`quiz.hint_difficulties`, сейчас — средний и сложный); `md2yaml.py` падает, если её нет.

Тест хранится на нескольких языках: `quiz.ru.md` и `quiz.en.md` рядом, `md2yaml.py` собирает их в один `quiz.yaml` и проверяет, что они совпадают (те же вопросы, сложность, число вариантов и подсказок, те же ✅). Метки языка («Вопрос»/«Question», «Подсказка:»/«Hint:», …) и строки интерфейса — в `lang.<код>` в `quizes/src/settings.yml`. Язык берётся из пресета (`lang`), иначе спрашивается при старте; чтобы не спрашивать, `make quiz 4 QUIZ_LANG=en` (или `just run <пресет> en` в каталоге теста). Раздел вроде «Переписанные вопросы» собирается только из `quiz.ru.md`.

Тема — необязательная строка `Тема: ...` у вопроса (по ней потом группируют и фильтруют вопросы).

В начале `quiz.ru.md` — front matter между строками `---`: `audience` (для кого), `purpose` (зачем), `goal` (цель), `context` (контекст), а также `prerequisites` и `duration_min`. Обязательные поля задаёт `quiz.meta_required`; значения пишите в двойных кавычках. `quiz.py` показывает «для кого», цель и время при старте и пишет все поля в лог (`run_start.meta`).
