# Тесты курса

Тексты тестов по модулям курса и ревью к ним.

| Файл | Что там |
|---|---|
| [`test-4-dagster.md`](test-4-dagster.md) | Тест 4 «Оркестрация данных и ML-пайплайнов в Dagster»: 10 вопросов, ответы с разбором и 5 резервных вопросов |
| [`test-3-dbt-review.md`](test-3-dbt-review.md) | Ревью теста 3 «Трансформация данных и витрины с dbt»: вердикт, замечания по каждому вопросу и переписанные варианты |

## Формат теста

- Метки уровня: 🟩 знание/понимание, 🟨 применение, 🟥 анализ.
- Правильный ответ отмечен ✅, после каждого вопроса идёт «Разбор».
- В вопросах с несколькими ответами: +1 балл за каждый верный выбор, −1 за лишний, итог не ниже 0 (в тесте 4 это вопросы 1 и 6).
- Сводка ответов стоит после основных вопросов.
- «Резерв» — вопросы для второй версии теста или пересдачи. Они в том же формате, но в основной тест не входят.

## Пройти тест в терминале

```bash
uv run --with pyyaml python quizes/md2yaml.py quizes/test-4-dagster.md            # md → yaml с самопроверкой
uv run --with pyyaml python quizes/md2yaml.py quizes/test-3-dbt-review.md          # тест и резерв, ревью пропускается
uv run --with pyyaml python quizes/md2yaml.py quizes/test-3-dbt-review.md "## Переписанные вопросы"  # только этот раздел
uv run --with questionary --with pyyaml python quizes/quiz.py quizes/test-4-dagster.yaml
```

Короче из корня репозитория: `make quiz 4` (или `make quiz 3`).

`quiz.py` задаёт только основные вопросы (без резерва), после ответа показывает баллы и «Разбор». Клавиши: цифры 1–9 выбирают вариант (в вопросах с несколькими ответами — отмечают и снимают отметку), Enter — ответить, `h` — показать подсказку отдельным пунктом над вопросом или под ним (`quiz.hint_key`, `quiz.hint_position` в `quizes/settings.yml`). Тесты клавиш: `uv run --with questionary --with pyyaml --with pytest pytest quizes/test_quiz.py`.

Подсказка — строка `Подсказка: ...` после вариантов ответа. Для каких уровней сложности подсказка обязательна и показывается, задаёт `quizes/settings.yml` (`quiz.hint_difficulties`, сейчас — средний и сложный); `md2yaml.py` падает, если её нет.

## Как менять тест

- После правки пересчитайте метки уровня и сверьте их с шапкой файла.
- Сверьте строку «Ответы» с ✅ в тексте вопросов.
- Правильный вариант не должен быть самым длинным в списке.
