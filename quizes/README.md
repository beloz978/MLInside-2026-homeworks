Тексты тестов по модулям курса и ревью к ним.

| Файл | Что там |
|---|---|
| [`quiz-4-dagster/`](quiz-4-dagster/README.md) | Тест 4 «Оркестрация данных и ML-пайплайнов в Dagster»: 10 вопросов, ответы с разбором и 5 резервных вопросов |
| [`quiz-3-dbt-review/`](quiz-3-dbt-review/README.md) | Ревью теста 3 «Трансформация данных и витрины с dbt»: вердикт, замечания по каждому вопросу и переписанные варианты |

## Формат теста и правила правки

- Метки уровня: 🟩 знание/понимание, 🟨 применение, 🟥 анализ.
- Между текстом вопроса и вариантами ответа стоит строка `---` (с пустыми строками вокруг); `md2yaml.py` её пропускает.
- Правильный ответ отмечен ✅, после каждого вопроса идёт «Разбор».
- В вопросах с несколькими ответами: +1 балл за каждый верный выбор, −1 за лишний, итог не ниже 0 (в тесте 4 это вопросы 1 и 6).
- Сводка ответов стоит после основных вопросов.
- «Резерв» — вопросы для второй версии теста или пересдачи. Они в том же формате, но в основной тест не входят.

### Как менять тест

- После правки пересчитайте метки уровня и сверьте их с шапкой файла.
- Сверьте строку «Ответы» с ✅ в тексте вопросов.
- Правильный вариант не должен быть самым длинным в списке.

## Структура

```
quizes/
├── src/             общий код и базовые настройки (quiz.py, md2yaml.py, settings.py, settings.yml, тесты)
└── quiz-N-<тема>/   один тест: quiz.ru.md, quiz.yaml, settings.yml, Justfile, README.md, logs/
```

## Пройти тест в терминале

Из корня репозитория (нужен `uv`):

```bash
make quiz-yaml 4                                     # md → yaml с самопроверкой
make quiz-yaml 3                                     # тест и резерв, ревью пропускается
make quiz-yaml 3 SECTION="## Переписанные вопросы"   # только этот раздел
make quiz 4                                          # пройти тест (или make quiz 3)
make quiz-test                                       # тесты клавиш quiz.py
```

`quiz.py` задаёт только основные вопросы (без резерва), после ответа показывает баллы и «Разбор». Клавиши: цифры 1–9 выбирают вариант (в вопросах с несколькими ответами — отмечают и снимают отметку), Enter — ответить, `h` — показать подсказку отдельным пунктом над вопросом или под ним (`quiz.hint_key`, `quiz.hint_position` в `quizes/src/settings.yml` (базовые) или `quizes/quiz-N-*/settings.yml` (переопределения)), `p` — пауза: таймер вопроса стоит, продолжить — любой клавишей (`quiz.pause_key`).

Каждый запуск пишет лог в `logs/` своего теста (он хранится в git): `quizes/quiz-N-*/logs/<yymmdd-HHMMSS>-<тест>-<пользователь>.jsonl`, одно событие на строку с временем (`t`, `ms` от старта) и id вопроса. События: `run_start` (кто — пользователь, хост, git user.name/email; где — файл теста, каталог, коммит, Python, ОС), `question_shown`, `move` (курсор), `choose` / `unchoose` (вариант и клавиша), `hint_shown`, `pause` / `resume`, `answer` (выбор, верные, баллы, время без пауз, подсказка, число переключений), `run_end` или `interrupted`. Кто проходит, задаёт `log.identity` в `quizes/src/settings.yml` (базовые) или `quizes/quiz-N-*/settings.yml` (переопределения): `os_git` (по умолчанию — пользователь ОС), `ask` (спросить имя при старте) или `env` (переменная из `log.identity_env`, без неё — ошибка).

Подсказка — строка `Подсказка: ...` после вариантов ответа. Для каких уровней сложности подсказка обязательна и показывается, задаёт `quizes/src/settings.yml` (`quiz.hint_difficulties`, сейчас — средний и сложный); `md2yaml.py` падает, если её нет.
