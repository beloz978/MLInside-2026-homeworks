## Формат теста и правила правки

- Метки уровня: 🟩 знание/понимание, 🟨 применение, 🟥 анализ.
- Между текстом вопроса и вариантами ответа стоит строка `---` (с пустыми строками вокруг); `md2yaml.py` её пропускает.
- Правильный ответ отмечен ✅, после каждого вопроса идёт «Разбор».
- В вопросах с несколькими ответами: +1 балл за каждый верный выбор, −1 за лишний, итог не ниже 0 (в тесте 4 это вопросы 1 и 6).
- Сводка ответов стоит после основных вопросов.
- «Резерв» — вопросы для второй версии теста или пересдачи. Они в том же формате, но в основной тест не входят.

### Как менять тест

- После правки пересчитайте метки уровня и сверьте их с шапкой файла.
- Сверьте строку «Ответы» с ✅ в тексте вопросов.
- Правильный вариант не должен быть самым длинным в списке.

## Пройти тест в терминале

Из корня репозитория (нужен `uv`):

```bash
make quiz-yaml 4                                     # md → yaml с самопроверкой
make quiz-yaml 3                                     # тест и резерв, ревью пропускается
make quiz-yaml 3 SECTION="## Переписанные вопросы"   # только этот раздел
make quiz 4                                          # пройти тест (или make quiz 3)
make quiz-test                                       # тесты клавиш quiz.py
```

`quiz.py` задаёт только основные вопросы (без резерва), после ответа показывает баллы и «Разбор». Клавиши: цифры 1–9 выбирают вариант (в вопросах с несколькими ответами — отмечают и снимают отметку), Enter — ответить, `h` — показать подсказку отдельным пунктом над вопросом или под ним (`quiz.hint_key`, `quiz.hint_position` в `quizes/src/settings.yml`).

Подсказка — строка `Подсказка: ...` после вариантов ответа. Для каких уровней сложности подсказка обязательна и показывается, задаёт `quizes/src/settings.yml` (`quiz.hint_difficulties`, сейчас — средний и сложный); `md2yaml.py` падает, если её нет.
