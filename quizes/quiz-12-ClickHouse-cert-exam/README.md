# Тест 12. ClickHouse Certified Developer — пробный экзамен

Один пробный экзамен в объёме настоящего: 12 заданий по 5 официальным областям (формулировки на английском, разбор на русском), плюс 6 резервных вопросов для пересдачи. Все решения проверены на ClickHouse 26.11. Режим по умолчанию — экзаменационный: пресет `exam`.

| Файл | Что там |
|---|---|
| [`quiz.ru.md`](quiz.ru.md) | Текст теста (источник правды) |
| `quiz.yaml` | Сгенерированный из md файл для `quiz.py` |
| [`settings.yml`](settings.yml) | Настройки этого теста поверх [базовых](../src/settings.yml) |
| [`presets.yaml`](presets.yaml) | Пресеты: `exam` (по умолчанию), `retake`, `weak-areas` + базовые `practice`, `drill` |
| [`logs/`](logs/) | Логи прохождений (JSONL, в git) |
| [`Justfile`](Justfile) | Команды запуска из этого каталога |
| [`session/`](session/README.md) | Контекст сессии, в которой сделан тест: промпты, материалы, проверочные SQL |

## Запуск

```bash
just                   # экзамен: пресет exam по умолчанию
just run practice      # тренировка с подсказками и разбором после каждого ответа
just run retake        # 6 резервных вопросов в экзаменационном режиме
just presets           # список пресетов
just verify            # прогнать проверочные SQL на локальном clickhouse
just yaml              # quiz.ru.md → quiz.yaml
```

## Что значит «экзаменационный режим»

| Настоящий экзамен | Пресет `exam` |
|---|---|
| 10–12 заданий | 12 вопросов, все основные |
| порядок заданий не подсказывает сложность | случайный порядок и перемешанные варианты (метка уровня в заголовке вопроса пока показывается — это общее поведение `quiz.py`) |
| нет обратной связи по ходу | разбор и промпты только после последнего вопроса |
| подсказок нет | подсказки отключены |
| 2 часа | ориентир 120 минут (`duration_min`), контроль времени — по логу (`ms_total`) |
| порог 70% | 9 из 12 |
| ответ правильный или нет | один верный вариант в каждом вопросе |

Ограничение: настоящий экзамен — практический (SQL в `clickhouse-client`), а здесь выбор решения. Чтобы тренировать набор текста и навигацию по документации, используйте банк заданий презентации (`exam-bank/`) и `session/materials/smoke-test.sql`.
