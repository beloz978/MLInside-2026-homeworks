## Факты об экзамене (официально, на 2026-10)

- Практический: 10–12 заданий в `clickhouse-client` (среда HackerRank), 2 часа (+5–10 мин на подготовку), порог 70%, вес заданий разный.
- Документация и другие страницы clickhouse.com разрешены, ИИ-инструменты запрещены, прокторинг по веб-камере, один монитор.
- $200 за попытку, пересдача через 7 дней, попытка действует 365 дней, сертификат бессрочный. Вес областей и версия ClickHouse не публикуются.
- 5 областей / 19 целей: Modeling · Inserting · Analyzing · Optimizing · Dedup and mutations (подробнее — `materials/exam-facts.md`, `materials/objectives.yaml`).

## Проверенные «ловушки» (ClickHouse 26.11.1.4)

Скрипты — в `verify/`; запускаются командой `just verify`.

| Область | Ловушка | Вопрос |
|---|---|---|
| D1 | `dictGet('словарь','атрибут',ключ)`: порядок аргументов, `joinGet` не для словарей | 2 |
| D2 | `file()` читает файлы сервера, `FROM INFILE` — клиента; `SELECT *` в `INSERT` молча даёт `1970-01-01` | 3, 4 |
| D3 | `quantile(0.95)(col)`; `ILIKE` против `LIKE`; `percentile` не существует | 5, 6 |
| D4 | MV без backfill; `uniq` по колонке состояния молча неверен; `ADD INDEX` без `MATERIALIZE INDEX` | 7, 8, 9 |
| D5 | Code 344 при `DELETE` с проекцией; `FINAL` для ReplacingMergeTree; пара строк отмены в CollapsingMergeTree; `ReplacingMergeTree(is_deleted)` = версия | 10, 11, 12, резерв 6 |

Остальные проверенные факты (async_insert, `EXCEPT ALL`, `toStartOfWeek` с воскресенья, `WITH FILL` без `STEP` шагает по секунде, refreshable MV требует Atomic) использованы в презентации и банке заданий, но не в этом тесте.

## Тонкости среды

- Публичный S3 (`datasets-documentation`) из облачной песочницы отдавал 403: загрузку с S3 нужно подтвердить на своём компьютере.
- Для практики: Docker `clickhouse/clickhouse-server:latest` или `clickhouse local` (см. `materials/environment.md`).

- Формат и движок — как у `quiz-5-gcp-adp`: `quiz.ru.md` → `quiz.yaml` (md2yaml), запуск `quiz.py`.
