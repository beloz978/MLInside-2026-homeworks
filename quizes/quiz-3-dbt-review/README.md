# Тест 3. Трансформация данных и витрины с dbt (ревью)

Ревью теста 3: вердикт, замечания по каждому вопросу и переписанные варианты. Спрашиваются тест и резерв, ревью пропускается.

| Файл | Что там |
|---|---|
| [`quiz.ru.md`](quiz.ru.md) | Текст теста и ревью (источник правды) |
| `quiz.yaml` | Сгенерированный из md файл для `quiz.py` |
| [`settings.yml`](settings.yml) | Настройки этого теста поверх [базовых](../src/settings.yml) |
| [`logs/`](logs/) | Логи прохождений (JSONL, в git) |
| [`Justfile`](Justfile) | Команды запуска из этого каталога |

## Запуск

```bash
just                                  # пройти тест (из этого каталога)
just yaml "## Переписанные вопросы"   # собрать yaml только из этого раздела
just yaml                             # quiz.ru.md → quiz.yaml (тест и резерв)
make quiz 3                           # то же из корня репозитория
```

Формат теста и правила правки — в [`../README.md`](../README.md#формат-теста-и-правила-правки).
