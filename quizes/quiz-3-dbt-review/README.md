# Тест 3. Трансформация данных и витрины с dbt (ревью)

Ревью теста 3: вердикт, замечания по каждому вопросу и переписанные варианты. Спрашиваются тест и резерв, ревью пропускается.

| Файл | Что там |
|---|---|
| [`quiz.ru.md`](quiz.ru.md) | Текст теста и ревью (источник правды); [`quiz.en.md`](quiz.en.md) — тест и резерв на английском, без ревью |
| `quiz.yaml` | Сгенерированный из md файл для `quiz.py` |
| [`presets.yaml`](presets.yaml) | Пресеты этого теста поверх [базовых](../src/presets.yaml) |
| [`settings.yml`](settings.yml) | Настройки этого теста поверх [базовых](../src/settings.yml) |
| [`logs/`](logs/) | Логи прохождений (JSONL, в git) |
| [`Justfile`](Justfile) | Команды запуска из этого каталога |

## Пресеты

| Пресет | Что это |
|---|---|
| `practice` | Тренировка: все основные вопросы по порядку, разбор после каждого ответа |
| `exam` | Экзамен: основные вопросы от простых к сложным, варианты перемешаны, без подсказок, разбор в конце |
| `drill` | Отработка: основные и резервные вопросы средней и высокой сложности вперемешку, по темам |
| `quick` | Быстрая проверка: 5 случайных основных вопросов |
| `tests` | Только про тесты данных и снапшоты (основные и резерв) |

## Запуск

```bash
just                                  # пройти тест: пресет и язык спросят при старте
just run exam en                      # сразу пресет exam на английском
just presets                          # список пресетов
just yaml                             # quiz.<язык>.md → quiz.yaml (тест и резерв)
just yaml "## Переписанные вопросы"   # собрать yaml только из этого раздела (только quiz.ru.md)
make quiz 3 PRESET=exam QUIZ_LANG=en  # то же из корня репозитория
```

Формат теста и правила правки — в [`../README.md`](../README.md#формат-теста-и-правила-правки).
