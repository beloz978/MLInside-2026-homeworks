# Google Cloud Associate Data Practitioner — факты (проверено 2026-10-06)

- Длительность 2 часа, 50–60 вопросов, multiple choice и multiple select.
- Стоимость $125, языки English и Japanese, онлайн с прокторингом или в тестовом центре.
- Рекомендуемый опыт: 6+ месяцев работы с данными в Google Cloud, пререквизитов нет.
- Exam guide v1.0, домены:
  - S1 Data preparation and ingestion ~30% (1.1 prepare and process data; 1.2 extract and load into storage)
  - S2 Data analysis and presentation ~27% (2.1 SQL, Colab Enterprise; 2.2 Looker / Looker Studio / LookML; 2.3 BigQuery ML, remote LLM models, Model Registry)
  - S3 Data pipeline orchestration ~18% (3.1 выбор инструмента трансформации, ETL/ELT; 3.2 scheduled queries, Composer, Workflows, Dataproc Workflow Templates, Eventarc, Pub/Sub → BigQuery, Dataflow job UI, Logging/Monitoring)
  - S4 Data management ~25% (4.1 IAM, доступ к GCS, Analytics Hub; 4.2 storage classes, lifecycle, архив; 4.3 backup/replication/locations; 4.4 CMEK/CSEK/GMEK, Cloud KMS, encryption in transit/at rest)
- Переименования: BigLake → Lakehouse (с 20.04.2026), BigLake metastore → Lakehouse runtime catalog, Data Catalog → Dataplex Universal Catalog. Гайд v1.0 использует старые названия.

## Правила (Exam Terms & Conditions)
- §3: вопросы, ответы и любые обсуждения экзамена — конфиденциальная информация Google.
- §5.a.vi–vii: запрещено делиться содержимым экзамена и использовать чужие опубликованные материалы экзамена («brain dumps»).
- §5.a.xi: запрещены AI-инструменты во время экзамена.
- §8: аннулирование результата, отзыв любых или всех сертификатов, временный или постоянный бан, без возврата денег.

Поэтому все вопросы теста написаны с нуля по гайду и документации, дампы не использовались.
