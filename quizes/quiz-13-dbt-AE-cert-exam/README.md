# Тест 13. dbt Analytics Engineering Certification — пробный экзамен

Один пробный экзамен в объёме настоящего: 65 вопросов по семи доменам study guide dbt 1.11 (формулировки на английском, разбор на русском). Режим по умолчанию — экзаменационный: пресет `exam`.

| Файл | Что там |
|---|---|
| [`quiz.ru.md`](quiz.ru.md) | Текст теста (источник правды) |
| `quiz.yaml` | Сгенерированный из md файл для `quiz.py` |
| [`settings.yml`](settings.yml) | Настройки этого теста поверх [базовых](../src/settings.yml) |
| [`presets.yaml`](presets.yaml) | Пресеты: `exam` (по умолчанию), `sprint`, `hard` + базовые `practice`, `drill` |
| [`logs/`](logs/) | Логи прохождений (JSONL, в git) |
| [`Justfile`](Justfile) | Команды запуска из этого каталога |
| [`session/`](session/README.md) | Контекст сессии, в которой сделан тест: запросы, план, факты об экзамене, решения |

## Запуск

```bash
just                   # экзамен: пресет exam по умолчанию
just run practice      # тренировка: вопросы по порядку, разбор после каждого ответа
just run sprint        # 20 случайных вопросов в экзаменационном режиме
just run hard          # только 15 сложных вопросов
just presets           # список пресетов
just yaml              # quiz.ru.md → quiz.yaml
```

## Что значит «экзаменационный режим»

| Настоящий экзамен | Пресет `exam` |
|---|---|
| 65 вопросов | 65 вопросов, все основные |
| 120 минут | ориентир 120 минут (`duration_min`); `quiz.py` время не ограничивает, фактическое время — в логе (`ms_total`) |
| порядок не подсказывает сложность | случайный порядок и перемешанные варианты (метка уровня в заголовке вопроса пока показывается — это общее поведение `quiz.py`) |
| нет обратной связи по ходу | разбор и промпты только после последнего вопроса |
| подсказок нет | подсказок нет ни в тексте, ни в пресете |
| проходной балл 65% | 65% от максимума: 45 из 69 баллов |
| 1 балл за вопрос | 1 балл за вопрос; в 4 вопросах с несколькими ответами +1 за верный выбор и −1 за лишний (максимум 2 балла), поэтому максимум 69 |

Ограничения: на настоящем экзамене нет примера «выбери два» с отрицательными баллами, а набор вопросов здесь — авторский, по официальному study guide, без дампов.
