# Скрипты для ДЗ по Dagster

Готовых скриптов и автопроверки для Dagster в этом репозитории нет: [задание](../ДЗ/ДЗ_Dagster_Olist.md) выполняется в вашем собственном проекте Dagster (вместе с dbt-проектом из [ДЗ по dbt](../../dbt/README.md)).

Данные и эталонные цифры — те же, что в ДЗ по dbt; скрипты для них описаны в [`../../dbt/scripts/README.md`](../../dbt/scripts/README.md): например, `fetch_olist_seeds.py` скачивает Olist через `kagglehub`.
