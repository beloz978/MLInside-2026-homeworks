Возьмите dbt-проект из [ДЗ по dbt](../dbt/README.md) (датасет **Olist**) и оркестрируйте его в Dagster: от входных данных до витрин, а на высшую оценку — до обученной модели. Полный текст: [ДЗ/ДЗ_Dagster_Olist.md](ДЗ/ДЗ_Dagster_Olist.md).

```
входные данные → raw → dbt (staging → marts) → (на 10) модель
```

Здесь текст задания и скрипты самопроверки (`make check`, пока критерии 1–9: [scripts/README.md](scripts/README.md)); план автопроверки и эталонного решения — [PLAN.md](PLAN.md). Данные и эталонные цифры — те же, что в ДЗ по dbt (`kagglehub.dataset_download("olistbr/brazilian-ecommerce")`; ожидаемые числа строк — в [ДЗ по dbt](../dbt/ДЗ/ДЗ_dbt_Olist.md), раздел 0).

## Что нужно сделать

0. **Тест по теме.** Сначала пройдите [тест 4 «Dagster»](../quizes/quiz-4-dagster/quiz.ru.md): из корня репозитория `make quiz 4`.
1. **Граф ассетов.** Raw-ассет (на 6–9 баллов достаточно `dbt seed` или собственного ассета), dbt-модели как ассеты, dbt-тесты как asset checks. Единый lineage без разрывов; минимум — staging и 2 витрины.
2. **Запуск и расписание.** Ежедневное расписание; запуск вручную из интерфейса и из командной строки; секреты — не в репозитории.
3. **Документация.** README с установкой и запуском, скриншоты Global Asset Lineage и успешного запуска.
