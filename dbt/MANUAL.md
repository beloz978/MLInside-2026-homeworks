# MANUAL — как проверить своё ДЗ по dbt (Olist)

Нужны: [uv](https://docs.astral.sh/uv/), `make`, `git`. Все команды — из корня этого репозитория, по одной.

**1. Поставить зависимости**

```bash
make setup
```

**2. Настроить: GitHub, путь к проекту, Postgres/ClickHouse (мастер задаст вопросы)**

```bash
make wizard
```

**3. Скачать данные Olist в `seeds/` вашего проекта (через kagglehub)**

```bash
make seeds
```

**4. Загрузить данные в хранилище (из каталога вашего dbt-проекта)**

```bash
cd <ваш-проект>/dbt && dbt deps && dbt seed
```

**5. Проверить готовность (инструменты, пути, доступность СУБД)**

```bash
make ready
```

**6. Получить оценку**

```bash
make check
```

В конце будет строка «Проект прошёл на N из 10 баллов» и список того, чего не хватает. Если в предыдущих ДЗ вы уже загрузили данные (например, в ClickHouse), пропустите шаги 3–4 или догрузите недостающие таблицы через `dbt seed`.

Текст задания: [ДЗ/ДЗ_dbt_Olist.md](ДЗ/ДЗ_dbt_Olist.md). Подробности — в [README.md](README.md).
